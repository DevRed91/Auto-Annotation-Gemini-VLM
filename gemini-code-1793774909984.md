# LLM Context: GaussFlaw / GeoCritic — Fine-Grained 3DGS Artifact Diagnosis & Rectification

> Legend: **[paper]** = stated in the paper. **[ours]** = a project decision filling a gap the paper leaves open. Never present an [ours] value as coming from the paper.

---

## 1. Paper summary [paper]

Global metrics (PSNR/SSIM/LPIPS) and image-level MOS hide localized 3DGS defects. The paper reframes quality assessment as answering **where** an artifact is (pixel-level saliency) and **what** it is (one of 8 classes), then uses that diagnosis to drive **targeted 3D rectification**.

### Taxonomy (8 classes, 3 groups)
| Group | Class | Description |
|---|---|---|
| Geometric / topological | Floater | Detached, foreground-like blobs unsupported by scene geometry |
| | Needle Stretch | Thin, elongated, spike-like primitives |
| | Structure Missing | Absent/incomplete structure from insufficient capacity |
| Opacity / blending | Transparent Haze | Veil-like opacity accumulation obscuring content |
| | Ghosting | Duplicated, trailing, or semi-transparent structures |
| Texture / photometric | Over-smooth | Overly smooth regions lacking surface detail |
| | High-frequency Blur | Loss of fine texture, sharp edges |
| | Specular Collapse | Spurious/unstable view-dependent highlights |

### GaussFlaw-80K dataset
- 80,049 region annotations, 14,289 rendered images, 468 intermediate/final models, 26 scenes, 5 source datasets.
- Format: **pixel-level region mask + one of 8 class labels** per region.
- Most frequent: High-frequency Blur 23.7%, Ghosting 23.2%; the other six share ~53.1%.
- Metrics — localization: AUC-J, NSS, CC, SIM, KLD. Classification: Acc@1, Acc@3, Macro-Recall, Macro-F1.

### GeoCritic model
- RGB encoder: SigLIP 2; geometry encoder: Depth Anything 3; both LoRA rank 16.
- 4 feature levels fused per level: `F_i = Fuse_i(Concat[P_r(R_i), Align(P_d(G_i))])`; FPN-style pixel decoder; CNN depth adapter injecting normalized depth gradients.
- Outputs: saliency `S ∈ [0,1]^{H×W}` and class map `C ∈ [0,1]^{K×H×W}`, K = 8.
- Loss: `L = 1.5·L_saliency + 1.0·L_class`; `L_saliency = L_fid(S,S*) + L_dist(Ŝ,Ŝ*)`; `L_class` = per-class sigmoid focal loss. GT saliency `S*` = Gaussian-kernel-smoothed annotation masks.
- Not specified in the available text: exact form of `L_fid`/`L_dist`, kernel σ, focal α/γ, input resolution.

### Rectification pipeline
1. **Region selection:** threshold `S`, take connected components as proposals, assign each a class by aggregating `C` over the component.
2. **Region lifting:** project Gaussians into multiple probe views (training/test cameras covering the region); aggregate class-specific evidence per Gaussian under **visibility**, **depth consistency** (projected depth vs rendered surface depth) and **surface support** constraints.
3. **Targeted operations** (applied in 3DGS training at iterations 8K, 15K, 23K of 30K; optimizer states of edited attributes are reset; no extra perceptual loss is added):
   - **Densification** — triangulate multi-view depth observations inside diagnosed regions into new seeds: scale multiplier 0.35, opacity 0.15, max 12,000 seeds/scene.
   - **Attribute correction** — see table below.
   - **Outlier pruning** — remove Gaussians that consistently appear as foreground outliers without surface support across views, under a conservative budget.

## 2. Flaw → operation table

`k` multipliers are [paper]. The parameter-space formulas are [ours]: we interpret multipliers as applying to **activated** values (opacity in [0,1], linear scale), which is the natural reading of `α ← 0.65α`.

| Class | Condition | Operation | Multiplier | PLY-space formula [ours] |
|---|---|---|---|---|
| Floater | detached (foreground outlier, no surface support across views) | prune | — | delete Gaussian |
| Floater | non-detached (attached / near valid surface) | opacity | 0.65 | `o' = logit(0.65·sigmoid(o))` |
| Needle Stretch | foreground outlier, no surface support | prune | — | delete Gaussian |
| Needle Stretch | otherwise | shrink largest axis | 0.75 | `log_s[argmax] += ln(0.75)` |
| Transparent Haze | — | opacity | 0.65 | `o' = logit(0.65·sigmoid(o))` |
| Ghosting | — | opacity | 0.65 | `o' = logit(0.65·sigmoid(o))` |
| Ghosting (anisotropic) | — | shrink largest axis | 0.90 | `log_s[argmax] += ln(0.90)` |
| Specular Collapse | — | higher-order SH | 0.70 | `f_rest_* *= 0.70` (DC `f_dc_*` untouched) |
| Structure Missing / Over-smooth / HF Blur | — | densification | — | training-time only (out of scope here) |

Notes:
- Position and rotation are never modified by attribute correction [paper].
- "Higher-order SH" = all bands of degree ≥ 1, i.e. every `f_rest_*` [ours, conventional reading].
- Pruning = deletion from the representation [paper: "removed"].
- Each trigger applies its correction once; in the paper corrections can compound across the three triggers. In the viewer, each user-confirmed correction is applied once [ours].

## 3. Gaps the paper does not specify → project defaults [ours]

All of these are tunable; expose them in the UI/config rather than hard-coding.

| Parameter | Default [ours] | Notes |
|---|---|---|
| Saliency threshold for region masks | 0.5 | |
| Minimum connected-component area | 64 px | drop smaller blobs |
| Probe views per region | 8 | cameras whose frustum covers the region's 3D bounds |
| Visibility test | alpha-blending weight `T·α > 0.01` at the pixel | |
| Depth-consistency tolerance | `|z_g − z_surf| < 0.02·z_surf` | relative to rendered depth |
| "Foreground outlier" | `z_g < z_surf − 0.05·z_surf` | in front of the surface beyond tolerance |
| Surface support | ≥ 3 neighbours within 2× own scale that pass depth consistency | |
| Multi-view agreement | selected in ≥ 60% of views where visible | |
| Anisotropic test (ghosting) | `s_max / s_mid > 3` | |
| Pruning budget | ≤ 2% of total Gaussians per pass | |
| Multi-class conflict | prune > scale > opacity > SH; apply each distinct operation at most once per Gaussian | |

## 4. Project scope (browser viewer)

This project is a browser viewer/annotator, **not** a 3DGS trainer. In scope:
1. Obtain 2D artifact masks + class labels (Gemini VLM annotations or click interaction; format matches GaussFlaw: region mask + 1 of 8 labels).
2. Lift masks to Gaussians (Section 3 defaults).
3. Visualize selected Gaussians.
4. Apply post-hoc edits from the Section 2 table (opacity / scale / SH / delete).
5. Export the edited scene as PLY.

Out of scope: densification, re-optimization, optimizer resets, training-schedule triggers.

## 5. Project conventions

- Stack: Vite + TypeScript, Three.js 0.180, SparkJS 2.0 (`@sparkjsdev/spark`), WebGPU compute.
- Shader languages: **GLSL** for Three.js materials (`/* glsl */` template strings, e.g. `vec3(1.0, 0.95, 0.0)`); **WGSL** for WebGPU compute (`vec3f(1.0, 0.95, 0.0)`). Do not mix them.
- Parameter spaces: PLY stores opacity as a **logit** and scales as **log**; SH as `f_dc_0..2` plus `f_rest_0..44` (degree 3, channel-major: `f_rest[c*15 + k]`). Runtime APIs may expose activated values — always check which space a value is in before applying a multiplier.
- Selection highlight colour: neon yellow `(1.0, 0.95, 0.0)` [ours — project styling choice, not from the paper].
